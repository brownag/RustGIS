**Proposed r.md outline (≤80 lines)**
1. `# R Scripts`. Intro (3 lines): runs on desktop, CLI and Python via local R; browser does not run R yet.
2. `## Install R` (install from CRAN, `install.packages(c("jsonlite", "sf"))`, `sf` only for geometry; RustGIS never installs packages).
3. `## Locate Rscript` (Locate Rscript… / Set Rscript / `RUSTGIS_RSCRIPT`; one compact numbered list of lookup order; refuses a non-Rscript).
4. `## Running gp.runR` (params table: `script`, `inputs`, `args`, `timeout_s`, `lang` optional; one CLI example; the run is one undo step).
5. `## What a script reads and writes` (harness table, 6 rows, trimmed).
6. `## Limits and failures` (1 MB script, 120 s default, failed run leaves project unchanged, one run at a time).
7. `## Who may run R` (reserved to you: plugins and MCP refused; AI Assistant asks every time; links to `../mcp.md`, `assistant.md`).
