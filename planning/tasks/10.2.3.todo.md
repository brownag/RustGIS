# 10.2.3 — Language as a gp.runR param
## Goal
Make the interface language an optional `lang` param of `gp.runR`, filled in by the UI dispatch path, and remove `Session.lang`.
## TODO items
- [ ] 1. Engine: add `pub lang: String` to `RParams` (gp.rs:77-83) and read it in `r_params` (gp.rs:88-114) with `ps(params, "lang").unwrap_or("")`.
- [ ] 2. Engine: in `r_start` (gp.rs:147) set `lang: p.lang` instead of `s.lang.clone()`.
- [ ] 3. Engine: add `"lang"?: "the interface language code (empty: English)"` to the `gp.runR` params string (gp.rs:48).
- [ ] 4. Engine: remove `pub lang: String` and its doc comment (lib.rs:263-266) and the `lang: String::new(),` initialiser (lib.rs:402).
- [ ] 5. Engine test: in `gp_run_r_passes_the_interface_language_to_r` (tests.rs:827-838) replace `s.lang = lang.into();` and the `json!({"script": script})` call with `json!({"script": script, "lang": lang})`.
- [ ] 6. UI: delete the sync block `if self.session.lang != self.shown_lang.code() { ... }` (ui-egui lib.rs:2111-2114).

## Notes
- Only consumer of `Session.lang`: gp.rs:147 (`lang: s.lang.clone()`); writer: ui-egui lib.rs:2112-2113; test: tests.rs:833. Grep confirms no others.
- All UI dispatch funnels through `RustGis::run` at crates/ui-egui/src/lib.rs:878 (`self.session.run(id, &params)` at :885). Ribbon, shortcuts, command search and palette call `self.run(...)` / `app.run(...)` (about 338 call sites in ui-egui; e.g. chrome.rs:457, panes.rs:2170, lib.rs:685, :1573). The few direct `app.session.run` calls in ui-egui never target `gp.runR`.
- `r_params` is shared by `run_r` (gp.rs:212) and `r_start` (gp.rs:122), so one parse covers both.
- `clean_lang` is applied at use in rustgis-r (crates/r/src/job.rs:15 and wire.rs export), so the raw string may be passed through.
- `ps` helper: crates/engine/src/cmd/mod.rs:83.
- Assistant path: `gp.runR` is user-only (engine plugins.rs:203, tests.rs:2342); the assistant's `gp.run` (assistant/src/tools.rs:212) cannot reach it with lang injected, so it falls back to English. Keep that in mind for 10.3.1.
- Do not touch: queue code (r_running, r_complete, next-run, PendingRun) and RNotice (10.3.1, 10.4.1).
- Risk: the Session no longer has a language, so a CLI or Python caller of `gp.runR` without `lang` gets English. That matches the spec.
